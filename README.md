# 🏛️ Анти-Гулаг (Anti-Gulag VPN)

> *«Объяви Гойду блокировкам до того, как они объявят её тебе.»*

Карманное средство индивидуальной цифровой защиты для граждан, уставших от белых списков, замедления ютуба со скоростью черепахи и вечных попыток товарища майора заглянуть в замочную скважину. 

Клиент собирает на лету бронебойные туннели через ядро **Xray-core**, прикидывается невинным просмотром котиков в браузере и аккуратно разделяет трафик так, чтобы Госуслуги работали дома, а запрещённые знания — через заграничные явки.

---

## ⚡ Особенности конспирации

* **Шифровки нового поколения:** Поддержка `vless://` со всеми современными маскировками — **Reality**, **XHTTP**, **gRPC**, **WebSocket** и старый добрый **TCP**. Пробивает ТСПУ так, будто пакетов никогда и не было.
* **Централизованный обком (Подписки через Gist):** Вбиваешь одну ссылку на сырой raw-конфиг или GitHub Gist — приложение само забирает явки, сохраняя выбранный сервер даже при обновлении списка.
* **Раздельный суверенитет (RunetFreedom):** Автоматическая маршрутизация по базам `geosite` и `geoip`. Зарубежные ресурсы идут на свободу, а российские сайты и сервисы крутятся напрямую, не вызывая подозрений.
* **Телевизор вне подозрений (Smart View & LAN bypass):** Локальные широковещательные и мультикаст-диапазоны (`224.0.0.0/4`, `255.255.255.255/32`) пущены в обход туннеля. Смартфон спокойно видит домашний ТВ, Яндекс Станцию и умные лампочки.
* **Шпионская кнопка в шторке (Quick Settings Tile):** Запуск и сворачивание Гойды в один тап из панели быстрых настроек Android 14+.
* **Селективная изоляция софта (Per-App Routing):** Решай сам, какие приложения пойдут в подполье, а какие останутся на суд местным провайдерам.
* **Автостарт на рассвете:** При перезагрузке смартфона сервис тихо восстанавливает защищённый периметр без лишнего шума.

## 🚀 Инструкция по побегу из чебурнета

### 1. Получение спецсредства
Скачай свежий файл **`app-release.apk`** со страницы [Releases](https://github.com/Iselivan06/antigulag-vpn/releases) и установи на смартфон с Android 7.0 или новее.

### 2. Ввод явок
Приложение понимает шифровки с полуслова:
* **Из буфера обмена:** Скопируй любую строку `vless://` — приложение само перехватит её при открытии и вежливо предложит добавить явку в реестр.
* **Через оптический прицел (QR):** Нажми **«Добавить явку»** $\rightarrow$ **«Сканировать QR»** и наведи камеру на код.
* **По партийной линии (Gist / Подписка):** Зажми кнопку **«+»** и вставь ссылку на подписку. Клиент подтянет список серверов и будет проверять обновления при каждом входе.

### 3. Боевое дежурство
1. Нажми большую красную кнопку **«ОБЪЯВИТЬ ГОЙДУ»**.
2. Разреши системе создание VPN-туннеля.
3. Убедись, что статус сменился на **«НА СВОБОДЕ (ЗАЩИЩЕНО)»**, а товарищ майор остался ни с чем.

## 🛠️ Сборка для товарищей инженеров

Если доверяешь только коду, скомпилированному своими руками:

```bash
# Клонируй подпольный цех
git clone https://github.com/Iselivan06/antigulag-vpn.git
cd antigulag-vpn

# Собери релизный APK без подписи
./gradlew assembleRelease
```
Скомпилированный файл будет ждать в app/build/outputs/apk/release/.
